# 双手配对、标定与融合

## 两只手对应哪两个 Tracker

原始左右手身份由 PICO 手追提供。设备 ID 只标识 Tracker，不能用 ID 大小推断左右。

每次录制开始时，`EgoBilateralTrackerPairing` 同时管理两侧的 `EgoWristTrackerPairing`：

1. 候选 Tracker 的有效位置必须距该侧腕部不超过 20 cm。
2. 与该侧第二近的合格候选要有至少 4 cm 的距离差。
3. 如果另一只手腕也有效，该 Tracker 必须比另一腕部至少近 4 cm。
4. 必须连续满足至少 30 次观测、0.30 秒；采样间隔超过 0.10 秒会重新计数。
5. 已绑定另一侧的 ID 不再参与本侧候选。
6. 配对锁定到本次录制结束，下一次重新判定。暂时掉线不把另一侧设备拿来替代。

两腕太近或交叉时可能没有可区分的候选。此时保持原始 PICO，不强行分左右。最初必须有该侧有效光学腕部，只有 Tracker、没有手追不能确定它属于哪只手。

以上是距离与连续性启发式配对，并非设备提供的解剖标签。原始手追误判或距离偏差很大时仍可能配错，必须根据 HUD/日志和实际佩戴核对。

## 每只手独立标定

两侧各自创建一个 `EgoWristFusion`，不共享采样、偏移或新鲜度状态。分别累积 90 个有效成对样本。

记 Tracker 位姿为 `(pT, qT)`，PICO 原始腕部为 `(pW, qW)`：

```text
位置偏移 d = inverse(qT) * (pW - pT)
旋转偏移 r = inverse(qT) * qW
```

位置取三个轴的样本中位数；旋转先统一四元数符号，再归一化平均。收满样本后，这两个偏移在本次录制中冻结。该方法把 PICO 腕部作为初始参考，不是独立真值标定。

## 标定后

```text
融合腕部位置 pF = pT + qT * d
融合腕部旋转 qF = qT * r

PICO 关节相对腕部位置 lj = inverse(qW) * (pj - pW)
PICO 关节相对腕部旋转 aj = inverse(qW) * qj

融合关节位置 = pF + qF * lj
融合关节旋转 = qF * aj
```

左右 26 个关节分别做这个计算，头部不变，原始 `poses.txt` 不被覆盖。这里没有让 Tracker 直接估计手指，也没有重写 PICO 的视觉算法。

## 失效处理与限制

- Tracker 无效或位置被判为陈旧：该侧回退到 PICO，另一侧继续处理。
- 已标定 Tracker 有效，但该侧 PICO 腕部不可用：仅输出融合手腕，其他关节写缺失占位，不冻结上一帧的手指形状。
- 未配对、未标定或没有 Tracker：维持该侧原始 PICO。
- API 位置连续约 0.5 秒保持不变会被拒绝；手追移动而 Tracker 不动时会提前拒绝；位置突跳会短暂隔离。这是启发式新鲜度判断，量化后的真实静止位置也可能被误拒绝。
- 腕带滑动、Tracker 与腕关节之间发生真实相对运动时，固定刚性偏移不再成立。需要新录制重新标定。
- 两种输入都位于 PICO 的追踪原点坐标系，不是外部测量得到的绝对世界坐标。重定位或重置原点会影响结果。
